SeatServe v2.0.7 - Reporting + Administration Cleanup

INSTALL
1. Stop npm run dev.
2. Extract this ZIP directly into the active app folder containing package.json.
3. Replace matching files.
4. Run: npm install
5. Run: npm run dev
6. Hard refresh the browser (Ctrl+F5).
