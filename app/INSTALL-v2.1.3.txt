SeatServe v2.1.3 - Final Pilot Security Patch

INSTALL
1. Stop npm run dev.
2. Extract this ZIP directly into the active app folder containing package.json.
3. Replace matching files.
4. Run: npm install
5. Run: npm run build
6. Run: npm run dev
7. Hard refresh the browser.

SET STAFF PINS
Administration > Settings > Staff Access
- Administration PIN
- Kitchen PIN
- Runner PIN
Leave a field blank to keep the existing PIN. PIN values are stored as SHA-256 hashes.

STAFF QR FLOW
Scan the Staff QR > choose Kitchen, Runner, or Administration > enter that role's PIN.
Runner access then asks the runner to select their active runner profile.
Authorization lasts for the current browser tab/session. Closing the tab/browser requires the PIN again.

GOOGLE SHEETS
This package updates google-apps-script/Code.gs so the three PIN hashes are included in Workspace Settings structured sync.
After replacing Code.gs, deploy a New version in Apps Script before using Sync Now.

IMPORTANT
Shared PINs are suitable for the SeatServe pilot but are not a replacement for individual user accounts/role authentication for broader production use.
